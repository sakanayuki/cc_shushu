| # | 決定 | 章 |
|---:|---|---|

### ルール・得点

| # | 決定 | 章 |
|---:|---|---|
| 10 | 被覆率の分母は**置きカードの面積** | 06 |
| 18 | 判定は**全カード停止後**に一括 | 06 |
| 19 | 獲得時、置きカードと重なっていた投げカードを**一緒に回収** | 06 |
| 20 | 過半数判定は**重なる全投げカードの面積合計**で行う | 06 |
| 21 | 獲得のみ・**部分点なし**（2値） | 06 |
| 22 | **手札制**（初期5枚／投げると減る／回収で戻る／0で終了） | 02 |
| 24 | どの置きカードにも重ならない投げカードは**除去され、失われる** | 02 / 06 |
| 23 | 得点は**難易度帯内でランダム** | 07 |
| 25b | 補充は**空いた難易度スロットで再計算** | 07 |
